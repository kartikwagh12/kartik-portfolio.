# Kartik Wagh — Portfolio

A responsive, mobile-friendly personal portfolio built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — all portfolio sections and page structure
- `style.css` — responsive design, themes, glass panels and animations
- `script.js` — mobile navigation, typewriter, theme switcher, optional UI sounds, scroll reveal, canvas particles and message draft
- `README.md` — setup notes

## Publish with GitHub Pages (phone or computer)
1. Open your `Kartik-portfolio` repository.
2. Upload/replace these four files in the repository root (same level as each other).
3. Commit the changes to the `main` branch.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Choose **main** and **/(root)**, then save.
7. Wait for GitHub Pages to publish the site.

## Before sharing publicly
- Check that your education details and project descriptions are accurate.
- Add real demo links only after the projects are published.
- Add a real resume PDF only after preparing one. The current resume button intentionally shows a notice instead of linking to a fake file.
- The feedback form opens the visitor's email app with a draft. It does not send or store messages automatically.
- Font Awesome and Google Fonts load from their CDNs, so those enhancements need an internet connection.

## Customize
Search `Kartik Wagh`, `Silvassa, India`, and project descriptions in `index.html` to update your information. The theme button cycles through teal, violet and blue accent palettes.
